What is Min heap ? 
->Parent Node << Child Node 

##Deletion in Min heap?
Time Complexity: O(log n) 
🔹 Steps:
1->  Store root (this is the minimum).
2->   Replace root with last element of heap.
3->  Remove last element (reduce heap size).
4->  Heapify Down (Bubble Down):
            Compare with left & right child.
            Swap with smaller child.
            Repeat until heap property is restored.



##Insertion in Min Heap
Time Complexity: O(log n)
🔹 Steps:
1-> Insert element at the end of heap (last index).
2->Heapify Up (Bubble Up):
    Compare with parent.
    If parent > current → swap.
    Move upward.
    Repeat until:
            Parent ≤ current
            OR node becomes root.



Removal (Delete Min) in Min Heap
Time Complexity: O(log n)

🔹 Steps:
1 → Store root element (this is minimum).
2 → Replace root with last element of heap.
3 → Remove last element (reduce heap size).
4 → Heapify Down (Bubble Down):
  Compare with left and right child.
  Swap with smaller child.
  Move downward.
  Repeat until:
    Children ≥ current
    OR node becomes leaf

->Continous sorting

Whenever we look smallest ->Use maxheap 
Whenever we look Largest ->Use Minheap
