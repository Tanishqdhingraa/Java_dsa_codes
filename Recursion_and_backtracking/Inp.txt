HOW TO THINK (MOST IMPORTANT)
--------------------------------------------------
Steps:

2. Define base case
3. Identify choices at each step
4. Draw recursion tree
5. Apply backtracking if needed


--------------------------------------------------
GENERIC BACKTRACKING TEMPLATE (JAVA)
--------------------------------------------------
void backtrack(List<List<Integer>> res, List<Integer> temp, int[] nums, int start){
    res.add(new ArrayList<>(temp));

    for(int i = start; i < nums.length; i++){
        // choose
        temp.add(nums[i]);

        // explore
        backtrack(res, temp, nums, i + 1);

        // un-choose (backtrack)
        temp.remove(temp.size() - 1);
    }
}
